# Currículo Web

Projeto prático de currículo web com HTML, CSS e JavaScript.

## Recursos

- Atualização do currículo enquanto os campos são preenchidos.
- Salvamento e remoção dos dados usando \`localStorage\`.
- Alternância de tema claro e escuro.
- Registro da última visita com cookie.

## Arquivos

- \`index.html\` — estrutura da página.
- \`style.css\` — estilos e tema escuro.
- \`script.js\` — interações e armazenamento no navegador.

## Como executar

Abra o arquivo \`index.html\` no navegador. Não é necessário instalar dependências.
